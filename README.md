# Shree Nagarjun Pharmaceuticals — frontend concept
Run `npm install` then `npm run dev`. Open http://localhost:3000. Node 20+ recommended. `npm run build` and `npm run typecheck` for verification.
Routes: /, /products, /products/[id], /about, /quality, /business, /contact, /admin.
Demo admin password: nagarjun-demo. Client-side only; not secure. Product edits and enquiries persist in localStorage on the same browser. No server, real messages, payment or medicine sales.
Images are crops from the supplied Instagram screenshot, not original high-resolution product photographs. Replace with approved brand assets before publication. Company history and GMP claim are from the supplied profile, not independently verified. Confirm approved labels, certification, contact details and rights before launch. No medical efficacy or dosage claims added.
